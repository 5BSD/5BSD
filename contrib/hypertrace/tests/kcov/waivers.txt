#  live-only  Reachable only with real kernel memory behaviour (a mapped top

#  future-feature  A disabled, unwired future feature kept in place.
#  invariant  An internal-consistency panic or a bound that the only callers
#             (named) cannot violate.
#  gap        No executable code: LLVM attributes a zero-count gap region to a
#             closing brace that follows a break or return.
#  infeasible Reachable in principle but not in bounded time (named); kept as
