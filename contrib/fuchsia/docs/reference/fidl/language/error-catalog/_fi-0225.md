## fi-0225: Type cannot be marked as non-zero twice {:#fi-0225}

This error occurs when a type is made non-zero twice. Usually, this occurs when the type is marked non-zero at both its use and declaration sites.

{% include "docs/reference/fidl/language/error-catalog/label/_bad.md" %}

```fidl
{% includecode gerrit_repo="fuchsia/fuchsia" gerrit_path="tools/fidl/fidlc/tests/fidl/bad/fi-0225.test.fidl" exclude_regexp="\/\/ (Copyright 20|Use of|found in).*" %}
```

To fix this error, only make the type non-zero once.

For example, you can remove `:nonzero` from the use site.

{% include "docs/reference/fidl/language/error-catalog/label/_good.md" %}

```fidl
{% includecode gerrit_repo="fuchsia/fuchsia" gerrit_path="tools/fidl/fidlc/tests/fidl/good/fi-0225-a.test.fidl" exclude_regexp="\/\/ (Copyright 20|Use of|found in).*" %}
```

You could also remove `:nonzero` from the alias declaration.

