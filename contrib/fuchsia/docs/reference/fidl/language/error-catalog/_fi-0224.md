## fi-0224: Cannot be non-zero {:#fi-0224}

This error occurs when you try to mark a type as non-zero that cannot be non-zero.

{% include "docs/reference/fidl/language/error-catalog/label/_bad.md" %}

```fidl
{% includecode gerrit_repo="fuchsia/fuchsia" gerrit_path="tools/fidl/fidlc/tests/fidl/bad/fi-0224.test.fidl" exclude_regexp="\/\/ (Copyright 20|Use of|found in).*" %}
```

To fix this error, remove the non-zero constraint:

{% include "docs/reference/fidl/language/error-catalog/label/_good.md" %}

```fidl
{% includecode gerrit_repo="fuchsia/fuchsia" gerrit_path="tools/fidl/fidlc/tests/fidl/good/fi-0224.test.fidl" exclude_regexp="\/\/ (Copyright 20|Use of|found in).*" %}
```

Only integral FIDL types may be constrained to non-zero values.
