261 unchanged source translation units (254 C, seven assembly) in 245 source

needed. Existing native compilation, CTF, object alias, link and installation
primitives are reused. Of 264 precise consumed-header contexts, 235 match existing
providers; 29 new views and scoped visibility updates cover the remainder.
No copied Make-generated header or object enters the native production graph.

## Actual checks

and CTF/debug controls, with sixteen logical CPUs. Per profile, the successful
log contains all 261 module compiler witnesses, 68,785 original/native consumed

A bounded scan of all 261 sources finds 115 SDT/DTrace/KTR/audit candidate lines,
including comments/macros. All eight compiled SDT sections/relocations are exact
against original Make. No live event delivery or audit completeness is claimed.
