## Qualified default-profile inventory (2026-11-06)

The source-owned //:world_package_inventory target consumes the complete selected
fresh-world archive providers. It partitions all 32,518 file/link destinations
into 445 package buckets and seven explicitly declared construction outputs.
The buckets are inventory, not 445 created/qualified pkg archives.

No file is classified by a hand-maintained pathname list. Package names come
from the source installation tags, including dbg/dev/lib and configured man
suffixes. Untagged files must exactly match a source-owned construction manifest,
including generated source artifact identity and metadata. Account, services,
login-class and manual database owners provide these declarations. Unknown,
missing, changed or duplicate construction claims fail. Tagged configuration
must be a regular file; duplicate files, conflicting directories, hardlink cycles,
missing targets and inconsistent hardlink inode metadata are rejected.

The zoneinfo tree supplies 622 records through its existing declared generated
metadata. These execution-time records cannot be obtained during Bazel analysis.
The inventory action consumes that metadata and all archive directory sidecars
as explicit inputs, using the selected SDK interpreter/runtime. It does not scan
host paths, invoke Make, run a hidden build or substitute a selected-program list.
The result is a declared JSON artifact; complete source-owned family templates,
dependencies and actual package creation remain the next integration work.

## Physical directories and package claims

Archive sets now forward directory sidecar dependencies as a depset. Both static
and generated-tree archive serializers add physical_directories to their existing
format-1 sidecar, retaining the existing selected package directories field.
This additive data exposes the complete policy already resolved from declared
mtree/account inputs and used for the actual tar. Package claims are kept separate
from physical permissions; source mtree parent policy does not automatically
assign those parents to every package.

The complete inventory exposes 1,202 physical directory destinations. Earlier
789-directory reports counted explicit/selected metadata and did not cover all
physical ancestors. The complete raw record/sidecar stream contains 16,628 repeated
directory records. Identical package claims are coalesced using canonical mode,
empty-flag and tag-order semantics; distinct package claims on one directory are
preserved. No package file or permission is synthesized from the host filesystem.

Thirteen actual hardlinks cross package ownership, including ar.1 to llvm-ar.1.
The inventory records their canonical target and both owners instead of imposing
an unsupported same-package restriction. Source toolchain package metadata already
declares its clang dependency. Complete native package serialization/dependency
parity for these relationships remains open; recording them is not proof of
installation or solver behavior.
