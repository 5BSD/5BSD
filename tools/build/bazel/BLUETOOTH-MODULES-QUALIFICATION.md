## Declared generation and configuration

USB device IDs are generated by the original usbdevs2h.awk from the maintained
usbdevs file, using native execution-config awk and the existing static cwd_exec.
The action declares its generator, data, tools, output and runtime libraries.
Stable input/library aliases let the generator write its original fixed header
name in the declared output directory; no shell, host awk or Python wrapper is
introduced. The host execution environment still supplies the ELF interpreter;
this comparison is not full source bootstrap or stronger sandbox qualification.
The actual native header is byte-identical to all twelve Make-generated headers
(two USB modules, three targets, two CTF/debug modes), SHA-256
bf9a1509a6c621b2fe092b10ae9508d26bb23abcd7b41b7669f00c2b50108f92,
295673 bytes. Actual generator execution metadata and the header are retained.

USB and bus option headers come from each actual target GENERIC config tree.
The original makeobjops-generated USB/bus/device interfaces are native declared
inputs. Narrow USB and Bluetooth header libraries preserve source package
boundaries. The maintained build-bsd kernel profile consumes existing explicit
module/install targets; no frontend API, signing or publication helper change is
required. The manual records this coverage.
