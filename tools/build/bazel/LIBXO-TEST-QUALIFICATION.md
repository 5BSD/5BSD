## Original harness bug and reference repair

The original add_testcase function left xo_fmt from the previous invocation when
a saved file had no explicit format suffix. Actual original listing produced 103
registrations but only 99 unique names: four repeated XP cases concealed the four
default-text fixtures. A local empty xo_fmt now resets each invocation in the
shared source used by both Make and Bazel. Actual installed native/Make listings
now match 103 unique names, including test_01/test_02/test_03/test_10. The listing
control uses the host ATF interpreter; native body execution is qualified below.

The newly reached four default cases initially failed because five old reference
files were stale. Source review confirms text is the default style and identifies
the added format strings, humanization/messages and colors in unchanged programs.
Both unchanged native and original Make programs produce output exactly matching
the already-maintained explicit-text (.T) expectations, including stderr. The
five stale default references are copied from those existing .T files; no expected
output was invented or generated from the new implementation to hide a failure.
Other saved formats and program/library implementations remain unchanged. These
repairs improve original Make tests as well as the native test adapter.

or expected failures, using installation-form binaries, the maintained shared

actual plugin symlink. No host path replacement, test-only library search patch,

options, bootstrap/cache/sandbox/reproducibility and measured CPU/RAM/disk gates
remain separate work. This batch is not system-wide completion or a performance
benchmark. It launches no VM and installs nothing on the host.
