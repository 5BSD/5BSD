# Selected-default libcrypto core on AMD64, ARM64 and RISC-V

Selected-default libcrypto core library producers are qualified within the scope below. This is the `NO_SUBDIR` core leaf, preserving the original default core options, assembly selection and ABI policy. Complete OpenSSL recursion, installation and packages remain mandatory work.

## Producers and interfaces

Source-owned selected lists preserve the actual original order: 987 AMD64 objects (949 C, 38 assembly), 970 ARM64 objects (955 C, 15 assembly), and 956 RISC-V C objects. Each has normal and large-PIC variants, giving 5,826 production compiler contexts. The three original ARM crypto ISA exceptions, `bn_nist.c` alias policy, original SSP flags and version map are retained. RISC-V's lack of assembly follows the original selection.

The normal installed archive is the default lazy `CcInfo` static-consumer input. The PIC archive has the same original member order. Every member is bound by digest to its actual compiler output. The actual shared link whole-archives that PIC archive in original order; the independent artifact test checks unreferenced API exports as well as ELF ABI and archive contracts. Expected archive order comes from the maintained source lists.

The target-derived `buildinf.h` retains the original platform, date and compiler-flag macro/string values. Its provenance comment differs truthfully; raw header equality is not claimed. Public headers and the private compilation contexts remain separate.

## Independent original controls and actual inputs

Untouched original core references preserve normal/PIC recipes, full raw logs, metadata, archives, DSO, debug files and staged installation. Their compiler receipts bind 535,208 physical consumed occurrences. The actual native action audit checks 535,240 lexical prerequisite pairs, reconciling 32 same-file aliases through exact resolved original identities and file digests. Each native consumed dependency must also be declared with matching digest in its actual action inputs. Source include order, defines, warnings, optimization, machine options and normal/PIC policy are checked against the actual original recipes.

Untouched-original allocated comparisons rejected absolute `/usr/src/` filename strings versus the native repository-relative spelling. Those rejections are retained. Independently rebuilt original controls add exactly `-fmacro-prefix-map=/usr/src/=` to the original recursive CFLAGS, retaining dependency flags, source paths and every other recipe token. Every control binds source, tools and consumed inputs before and after. This is an explicit filename-policy difference, not untouched-Make byte parity.

All 5,826 native object allocated-section payloads and runtime relocations match these controls. AMD64 and ARM64 also match all parsed object symbols. RISC-V's raw all-symbol comparison remains unequal in 1,868 objects: an exhaustive audit classifies all 300,356 differing entries as local offsets into nonallocated debug sections, with no other difference. All three complete DSOs match the controls for every allocated section and all parsed symbols. Separate DWARF equality and source lookup are open.

The actual archive/link actions are hash-bound to captured compiler/archive outputs, the original version map and each frozen r4 SDK receipt. Original-control and native frozen compiler, linker, archiver and objcopy bytes match. No live shared execroot symlink is used to infer tool identity. Raw compact execution logs are retained; complete decoded records use standard lossless XZ with verified uncompressed hash and record counts.

## Installation and tests

Each ABI's core installation has 6,465 metadata records. The audit checks destination, ownership, group, mode, flags, tags and symlink targets. All 6,460 header, manual and pkg-config payloads match original staged bytes. Native hardlink declarations are proved against original staged device/inode, target bytes and metadata for all 5,472 aliases. Original METALOG represents these aliases as `type=file`; this is physical installation equivalence, not raw-record equality. Initial raw-type rejection remains retained.

AMD64 executes the existing static and shared API tests. All three ABIs run the host artifact test; ARM64/RISC-V test programs are build-only inputs and never execute target ELF. The unchanged API fixture covers SHA256, AES-GCM and rejection, RAND, BN and Ed25519 signing/verification and rejection. Debuglink CRCs are independently checked; separate debug bytes are not equal.

## Remaining gates

Engines, legacy and FIPS providers, recursive tests, libssl, the actual openssl CLI, complete component/package closure and full selected world are unqualified here. Default recursion remains enabled in production Make. Provider/configuration/runtime-environment isolation, foreign execution, alternate options, bootstrap independence, separate DWARF/source lookup and publication are also open. This work creates no partial OpenSSL package and makes no FIPS-validation claim.

Frozen foreign r4 SDK objcopy provenance is separately under repair by the kernel qualification work: maintained CTF localization tests reject those stale tools. Libcrypto core emits no CTF. These results remain bound to the retained r4 receipts and do not imply qualification of future refreshed SDKs.
