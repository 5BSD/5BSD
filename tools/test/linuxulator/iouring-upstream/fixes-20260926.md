# Follow-up: hard-link fix and stream rollback — September 26, 2026

The [initial upstream qualification](results-20260926.md) exposed a kernel
assertion on `hardlink` and `ESPIPE` for io_uring transfers on pipes and eventfd.
Commit `d6a50b109f27` changed both paths. In a clean, focused VM, `hardlink`,
`pipe-eof`, and `eventfd` passed; three other stream and buffer cases timed out.
All five resource counters returned to zero and the VM shut down cleanly.

A broader rerun of those changes panicked during `io-cancel` process exit. The
trace reaches `sq_ctx_free → kqueue_close → witness_checkorder` after blocked
stream requests; it is retained in the [crash console](evidence-20260926/experimental-stream-crash.log.gz).
The run stopped at that panic after 35 completed cases, so it is **incomplete**.
The stream offset changes were rolled back in `df852c35a430`. The effective
kernel change retains only the empty-path lookup fix. This avoids advancing
stream I/O past an early `ESPIPE` until worker cancellation and teardown can be
made safe. `pipe-eof` and `eventfd` therefore remain known failures on the
current tree.

The clean experimental image was linked from the qualified object set with
only `vfs_lookup.o`, `sys_generic.o`, and `sys_squeue.o` rebuilt. A separate
whole-kernel build was blocked by an unrelated compile error in the concurrently
modified `kern_proc.c`; an image linked after that failed build faulted before
tests and was excluded. The accepted focus image and exact source hashes are
recorded in [the machine-readable follow-up](fixes-20260926.json).

The final hard-link-only image uses the same qualified object set with just
`vfs_lookup.o` replaced. It passed the upstream `hardlink` case, returned all five resource counters
to zero, and shut down cleanly. Its exact kernel hash and console digest are
recorded in the follow-up manifest.

[Final hard-link console](evidence-20260926/hardlink-final.log.gz) The initial 70-case baseline remains the relevant
compatibility measure for other io_uring operations, with `hardlink` requiring
this final verification.
